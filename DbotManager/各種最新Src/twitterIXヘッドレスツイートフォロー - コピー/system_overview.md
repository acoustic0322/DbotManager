# Twikit-Core-Bot

Twitterアカウントを自動運用するためのボットツールです。
人間のような自然な挙動（閲覧、いいね、ツイート）を全自動で行います。

## ✨ 機能

1.  **自動運用**: リストにあるアカウントを順番に処理します。
2.  **人間らしい挙動**:
    - **70%**: タイムラインを見るだけ（スクロールして待機）
    - **20%**: ランダムにいいね
    - **10%**: ツイート投稿（定型文からランダム）
3.  **BAN対策**:
    - 作業ごとのランダムな待機時間（ゆらぎ）
    - アカウント切り替え時の休憩時間
    - Cookieの自動保存・復元（再ログイン回避）
4.  **管理UI**: ブラウザから操作・監視が可能。

## 🚀 使い方

### 1. 起動する
ターミナルで以下を実行します（既に実行中の場合は不要です）。
```bash
streamlit run app.py
```
ブラウザが自動的に開き、管理画面が表示されます。

### 2. サイドバーメニュー（画面左）
- **ステータス**: ボットの稼働状況を表示。「ボットを起動」ボタンで開始、「ボットを停止」で中断します。
- **ナビゲーション**:
    - **ダッシュボード**: ログを見守る画面です。
    - **アカウント管理**: アカウントリストを編集する画面です。

### 3. アカウントの確認・追加
左メニューの「アカウント管理」をクリックします。
csvファイルの中身が表示されるので、必要に応じて編集し「変更を保存」を押してください。
（既にインポート済みのデータが入っています）

### 4. ボットを動かす
左側の「ボットを起動」ボタンを押してください。
「ダッシュボード」画面で、ボットが次々とアカウントにログインし、閲覧やいいねをする様子がログとして流れます。

## 📁 ファイル構成
- `app.py`: 管理画面のプログラム
- `main.py`: ボット本体のプログラム
- `data/accounts.csv`: アカウント情報
- `bot.log`: 実行ログ
